# BizzSimp

## What it is

BizzSimp turns a sales CSV into a plain-language comparison of recent monthly sales and one practical suggestion. It is for small online sellers who want an easy way to understand their sales data without charts or jargon.

## Run it

```sh
npm install
npm run dev
npm test
```

## CSV format

Use a CSV with these headers and dates in `YYYY-MM-DD` format:

```csv
date,item,quantity,price
2026-05-14,Ankara dress,2,30000
```

Files are processed in your browser and never stored.
